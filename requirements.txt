# =============================================================================
# Backend API + Pure-Python 3D Fallback Engine Runtime (Python 3.11.x)
# -----------------------------------------------------------------------------
# Every package below ships pre-compiled manylinux wheels for CPython 3.11,
# so installation NEVER compiles from source (no gcc/gfortran required):
#
#     pip install --only-binary=:all: -r requirements.txt
#
# IMPORTANT:
#   * Do NOT install `bpy` into this web-backend environment. Blender 4.2 LTS
#     runs in its own isolated runtime (see `requirements-blender.txt` and
#     `scripts/setup_blender_runtime.py`). When Blender is absent (e.g.
#     Render Native Python), the dual-engine dispatcher automatically uses
#     the built-in NumPy + Trimesh fallback engine instead.
#   * `pymeshlab` / `open3d` are OPTIONAL mesh-inspection accelerators and
#     intentionally live in `requirements-optional.txt` — they drag in large
#     Qt/OpenGL stacks that break slim/headless deploys. The capability
#     registry probes for them at runtime and degrades gracefully.
#   * Python is pinned to 3.11.11 via `.python-version`, `runtime.txt`, and
#     `PYTHON_VERSION` in `render.yaml`. Do not deploy on Python >= 3.12
#     until `bpy==4.2.23` (cp311-only) is upgraded.
# =============================================================================
